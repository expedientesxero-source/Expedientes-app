Ir a https://platform.openai.com/api-keys\n2. Crear API key\n3. Agregar a `.env`: `OPENAI_API_KEY=sk_...`\n\n**Costo:** $0.002 - $0.06 por 1K tokens\n\n### 2️⃣ HeyGen (Generación de Videos)\n**Para:** Crear videos con avatares IA\n**Setup:**\n1. Ir a https://www.heygen.com/api\n2. Solicitar acceso a API\n3. Obtener API key\n4. Agregar a `.env`: `HEYGEN_API_KEY=...`\n\n**Costo:** $20-100/mes según uso\n\n### 3️⃣ Stripe (Pagos)\n**Para:** Procesar pagos y suscripciones\n**Setup:**\n1. Crear cuenta en https://stripe.com\n2. Obtener API keys\n3. Crear productos y precios\n4. Configurar webhooks\n\n**Costo:** 2.9% + $0.30 por transacción\n\n### 4️⃣ MongoDB Atlas (Base de Datos)\n**Para:** Almacenar datos\n**Setup:**\n1. Crear cluster en https://www.mongodb.com/cloud/atlas\n2. Obtener connection string\n3. Agregar a `.env`: `MONGODB_URI=mongodb+srv://...`\n\n**Costo:** Free tier disponible (512MB storage)\n\n### 5️⃣ SendGrid (Email)\n**Para:** Enviar emails transaccionales\n**Setup:**\n1. Crear cuenta en https://sendgrid.com\n2. Obtener API key\n3. Verificar sender email\n4. Agregar a `.env`: `SENDGRID_API_KEY=SG_...`\n\n**Costo:** Free tier 100 emails/día\n\n---\n\n## Aplicaciones\n\n### 🌐 Web\n- **URL:** https://expedientes.app\n- **Plataforma:** Next.js\n- **Deploy:** Vercel\n- **Features:** Dashboard, AI Agent, Pagos\n\n### 📱 Mobile (iOS)\n- **Tecnología:** React Native / Expo\n- **App Store:** expedientes-app\n- **Features:** Todas las web + offline mode\n\n### 📱 Mobile (Android)\n- **Tecnología:** React Native / Expo\n- **Play Store:** expedientes-app\n- **Features:** Todas las web + offline mode\n\n### 💻 Desktop (Opcional)\n- **Tecnología:** Electron\n- **Plataformas:** Windows, Mac, Linux\n- **Features:** Editor offline, procesamiento local\n\n---\n\n## 📊 Estructura del Proyecto\n\n```\nExpedientes-app/\n├── packages/\n│   ├── backend/\n│   │   ├── src/\n│   │   │   ├── index.js              #
